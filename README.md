# Avis Sites

Un projet étudiant simple : rechercher, noter, partager des avis sur des sites web.

## Aperçu

Site vitrine statique en HTML/CSS, permettant de :
- Ajouter un site (nom, catégorie, note sur 5 étoiles)
- Rédiger un avis
- Consulter tous les avis de la communauté

## Démo en ligne

Une fois hébergé sur GitHub Pages, le lien sera disponible ici :
`https://TON-PSEUDO.github.io/avis-sites/`

## Technologies

- HTML5
- CSS3 (intégré)
- Police Inter (Google Fonts)
